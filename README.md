# 💪 WORKOUT APP

</div>

### Cross-platform mobile app for workout planning and tracking

---

## 📱 Features

- Create workouts based on templates  
- Track exercise completion with checkboxes  
- Create and manage workout templates  
- View and edit your workout history  
- Monthly calendar navigation  
- Local database for persistent storage

## 🚀 How to Run

### 🧑‍💻 From Source Code

1. Install Node.js (if not installed)
2. Install Expo CLI: `npm install -g expo-cli`
3. Clone repository: `git clone git clone https://github.com/droptrigger/workout-app.git`
4. Navigate to project folder: `cd workout-app`
5. Install dependencies: `npm install`
6. Start development server: `npm expo start`
7. On your phone:
   - Install **Expo Go** app
   - Scan QR code or open link
